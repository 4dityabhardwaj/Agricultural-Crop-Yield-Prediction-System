# Agricultural Crop Prediction System

A data analysis project focused on agricultural crop yield data using Python. The project includes data cleaning, exploratory data analysis, and visualization to understand crop yield patterns.

## Features
- Data cleaning and preprocessing
- Exploratory data analysis
- Data visualization
- Analysis of agricultural crop yield data

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Files
- `cleancrop.py` – Data cleaning and preprocessing
- `crop_analysis.py` – Crop yield data analysis
- `visualize.py` – Data visualization
- `crop_yield_cleaned.csv` – Cleaned dataset
- `crop_yield_messy.csv` – Original dataset

## Objective
To analyze agricultural crop yield data and identify patterns and insights through data processing and visualization.
